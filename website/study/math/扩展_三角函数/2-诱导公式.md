# 诱导公式
## 1. 奇偶性公式
### ① $-\alpha$
角 $-\alpha$ 是角 $\alpha~(\alpha \in (0, \frac{\pi}{2}))$ 关于 x 轴对称的角，根据图像可知，横坐标不变，纵坐标取反，即:  
$\sin(-\alpha) = -y = -\sin \alpha$  
$\cos(-\alpha) = x = \cos \alpha$  
$\tan(-\alpha) = -\frac{y}{x} = -\tan \alpha$

得到诱导公式 1:
<div id="formula">

$$\begin{align*}
\sin(-\alpha) &= -\sin \alpha \\
\cos(-\alpha) &= \cos \alpha \\
\tan(-\alpha) &= -\tan \alpha
\end{align*}
\tag{1}
$$
</div>

## 2. 周期性公式
### ② $2k\pi + \alpha$
角 $2k\pi + \alpha(k \in \mathbb{Z})$ 是角 $\alpha~(\alpha \in \mathbb{R})$ 旋转整数圈的角,终边不变，坐标不变.  
得到诱导公式 2:
<div id="formula">

$$\begin{align*}
\sin(2k\pi + \alpha) &= \sin \alpha  \\
\cos(2k\pi + \alpha) &= \cos \alpha  \\
\tan(2k\pi + \alpha) &= \tan \alpha
\end{align*}
\tag{2}
$$
</div>


## 2. 对称诱导公式
### ③ $\pi/2 - \alpha$  
角 $\frac{\pi}{2} - \alpha$ 是角 $\alpha~(\alpha \in (0, \frac{\pi}{2}))$ 关于直线 y=x 对称的角.  
* $\alpha~终边交点~P(x,y)$
* $\frac{\pi}{2} - \alpha~终边交点~P'(y,x)$
::: details 证明
$过点P作x轴的垂线段交于点A，过点P'作y轴的垂线段交于点B，原点为O(0,0)$  
$已知~\Delta POA~和~\Delta P'OB~都是直角三角形，PO=P'O，\angle POA=\angle P'OB=\alpha$  
$根据~AAS~可知~\Delta POA \cong \Delta P'OB$  
$则P'B=PA=y,BO=AO=x,即P'(y,x)$
:::
代入定义:  
$\sin(\frac{\pi}{2} - \alpha) = x = \cos \alpha$  
$\cos(\frac{\pi}{2} - \alpha) = y = \sin \alpha$  

得到诱导公式 3:
<div id="formula">

$$\begin{align*}
\sin(\frac{\pi}{2} - \alpha) &= \cos \alpha  \\
\cos(\frac{\pi}{2} - \alpha) &= \sin \alpha  \\
\tan(\frac{\pi}{2} - \alpha) &= \cot \alpha
\end{align*}
\tag{3}
$$
</div>

### ④ $\pi/2 + \alpha$  
角 $\frac{\pi}{2} + \alpha$ 是角 $\alpha~(\alpha \in (0, \frac{\pi}{2}))$ 绕原点逆时针旋转 90° 得到的角.  
* $\alpha~终边交点~P(x,y)$
* $\frac{\pi}{2} + \alpha~终边交点~P'(-y,x)$

::: details 证明
$\because 由①~易知~\Delta POA \cong \Delta P'OB$  
$且~P'~处于第二象限，P'(-,+)，x,y>0$  
$\Rightarrow P'(-x,y)$
:::

代入定义:  
$\sin(\frac{\pi}{2} + \alpha) = x = \cos \alpha$  
$\cos(\frac{\pi}{2} + \alpha) = -y = -\sin \alpha$

得到诱导公式 4:
<div id="formula">

$$\begin{align*}
\sin(\frac{\pi}{2} + \alpha) &= \cos \alpha  \\
\cos(\frac{\pi}{2} + \alpha) &= -\sin \alpha  \\
\tan(\frac{\pi}{2} + \alpha) &= -\cot \alpha
\end{align*}
\tag{4}
$$
</div>

### ⑤ $\pi - \alpha$
角 $\pi - \alpha$ 是角 $\alpha~(\alpha \in (0, \frac{\pi}{2}))$ 关于 y 轴对称的角.  
* $\alpha~终边交点~P(x,y)$
* $\pi - \alpha~终边交点~P'(-x,y)$

代入定义:  
$\sin(\pi - \alpha) = y = \sin \alpha$  
$\cos(\pi - \alpha) = -x = -\cos \alpha$

得到诱导公式 5:
<div id="formula">

$$\begin{align*}
\sin(\pi - \alpha) &= \sin \alpha  \\
\cos(\pi - \alpha) &= -\cos \alpha  \\
\tan(\pi - \alpha) &= -\tan \alpha
\end{align*}
\tag{5}
$$
</div>

<GeoGebraViewer url="/geogebra/三角函数对称诱导3.ggb" :height="550" />


### ⑥ $\pi + \alpha$
角 $\pi + \alpha$ 是角 $\alpha~(\alpha \in (0, \frac{\pi}{2}))$ 关于 y 轴对称的角.  
* $\alpha~终边交点~P(x,y)$
* $\pi + \alpha~终边交点~P'(-x,-y)$

代入定义:  
$\sin(\pi + \alpha) = -y = -\sin \alpha$  
$\cos(\pi + \alpha) = -x = -\cos \alpha$

得到诱导公式 6:
<div id="formula">

$$\begin{align*}
\sin(\pi + \alpha) &= -\sin \alpha  \\
\cos(\pi + \alpha) &= -\cos \alpha  \\
\tan(\pi + \alpha) &= \tan \alpha
\end{align*}
\tag{6}
$$
</div>

## 3 任意角的诱导公式
读者不难发现，以上诱导公式基本是基于第一象限的角 $\alpha~(\alpha \in (0, \frac{\pi}{2}))$ 得到的。  
而对于三角函数，基于其奇偶性和周期性，可以得出以下结论:  
三角函数的所有公式，只要在第一象限（锐角）成立，就可以严格推广到全体实数、所有象限。  

以 $\sin x = \cos(\frac{\pi}{2} - x)$ 为例.

① 第一象限:$0 < x < \frac{\pi}{2}$  
$\sin x = \cos(\frac{\pi}{2} - x)$

② 第二象限:$\frac{\pi}{2} < x < \pi$  
$令~x = \pi - \alpha,其中~\alpha \in (0, \frac{\pi}{2})$  
$左 = \sin (\pi - \alpha) = \sin \alpha$  
$右 = \cos (\frac{\pi}{2} - \pi + \alpha) = \cos (-(\frac{\pi}{2} - \alpha)) = \cos (\frac{\pi}{2} - \alpha) = \sin \alpha$  
$左 = 右，即\sin x = \cos(\frac{\pi}{2} - x)$

③ 第三象限:$\pi < x < \frac{3\pi}{2}$  
$令~x = \pi + \alpha,其中~\alpha \in (0, \frac{\pi}{2})$  
$左 = \sin (\pi + \alpha) = -\sin \alpha$  
$右 = \cos (\frac{\pi}{2} - \pi - \alpha) = \cos (\frac{\pi}{2} + \alpha) = -\sin \alpha$  
$左 = 右，即\sin x = \cos(\frac{\pi}{2} - x)$

④ 第四象限:$\frac{3\pi}{2} < x < 2\pi$  
$令~x = 2\pi - \alpha,其中~\alpha \in (0, \frac{\pi}{2})$  
$左 = \sin (2\pi - \alpha) = -\sin \alpha$  
$右 = \cos (\frac{\pi}{2} - 2\pi + \alpha) = \cos (2\pi - (\frac{\pi}{2} + \alpha)) = \cos (\frac{\pi}{2} + \alpha) = -\sin \alpha$  
$左 = 右，即\sin x = \cos(\frac{\pi}{2} - x)$

其他公式同理皆可推广到全体实数、所有象限。
