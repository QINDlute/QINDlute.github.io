# 投影定理
在任意 $\Delta ABC$ 中，记 A、B、C 为三个内角，对边: a = BC, b = AC, c = AB.有:
<div id=formula>

$$\begin{align*}
a = b\cos C + c\cos B \\
b = a\cos C + c\cos A \\
c = a\cos B + b\cos A
\end{align*}$$
</div>

---
<Badge type="note">证:</Badge>
<br>

$过~A~作~AD \perp BC,垂足为~D.$  
$\left\{\begin{matrix} 
    BD = c\cdot\cos B \\  
    CD = b\cdot\cos C \\
    a = BD + CD
\end{matrix}\right. \Rightarrow a = b\cos C + c\cos B
$  
另外两边同理.
