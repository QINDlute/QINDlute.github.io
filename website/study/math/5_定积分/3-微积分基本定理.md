# 微积分基本定理
&emsp;&emsp;(1) 定义:设函数 $f(x)$ 在区间 $[a,b]$ 上可积，则称 $\Phi(x) = \int_a^x f(t)\mathrm{d}t,a \le x \le b$ 为变上限积分(积分上限函数)；  
&emsp;&emsp;(2) 性质:若 $f(x)$ 在 $[a,b]$ 上可积，则 $F(x) = \int_a^x f(t) \mathrm{d}t$ 在 $[a,b]$ 上连续；  
&emsp;&emsp;(3) 定理:  
&emsp;&emsp;<Badge type="danger">① 微积分第一基本定理</Badge>

&emsp;&emsp;若函数 $f(x)$ 在区间 $[a,b]$ 上连续，则变上限积分 $\Phi(x) = \int_a^x f(t)\mathrm{d}t$ 在 $[a,b]$ 上可导，且
$$
\Phi'(x) = \Big(\int_a^x f(t)\mathrm{d}t\Big)' = f(x),a \le x \le b;
$$

&emsp;&emsp;<Badge type="danger">② 微积分第二基本定理</Badge>

&emsp;&emsp;设 $f(x)$ 在区间 $[a,b]$ 上连续，$F(x)$ 是 $f(x)$ 在区间 $[a,b]$ 上的一个原函数，则
$$
\int_a^b f(x)\mathrm{d}x = F(b) - F(a).
$$
