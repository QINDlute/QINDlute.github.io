# 不定积分-工具
## (一) 基本公式
1. 常数  
$\begin{align*}\int k\mathrm{d}x = kx + C\end{align*}$

2. 幂函数不定积分公式  
① $\begin{align*}a \ne -1:\int x^a\mathrm{d}x = \frac{1}{a+1}x^{a+1} + C;\end{align*}$  
② $\begin{align*}a=-1:\int x^{-1}\mathrm{d}x = \ln |x| + C;\end{align*}$
::: details 简单证明
$\because x < 0 时,[\ln (-x)]' = \frac{1}{x},\therefore \int \frac{1}{x}\mathrm{d}x = \ln (-x) + C.$  
$x > 0 时,(\ln x)' = \frac{1}{x},\therefore \int \frac{1}{x}\mathrm{d}x = \ln x + C.$  
$\therefore \int \frac{1}{x}\mathrm{d}x = \ln |x| + C.$
:::

3. 指数函数  
① $\begin{align*}a \ne e:\int a^x\mathrm{d}x=\frac{a^x}{\ln a} + C;\end{align*}$  
② $\begin{align*}a = e:\int e^x\mathrm{d}x = e^x + C;\end{align*}$

4. 三角函数  
① $\begin{align*}\int \sin x\mathrm{d}x = -\cos x + C;\end{align*}$  
② $\begin{align*}\int \cos x\mathrm{d}x = \sin x + C;\end{align*}$  
③ $\begin{align*}\int \tan x\mathrm{d}x = \ln |\sec x| + C;\end{align*}$  
④ $\begin{align*}\int \cot x\mathrm{d}x = \ln |\sin x| + C;\end{align*}$  
⑤ ⭐$\begin{align*}\int \sec x\mathrm{d}x = \ln |\sec x + \tan x| + C;\end{align*}$  
⑥ ⭐$\begin{align*}\int \csc x\mathrm{d}x = \ln |\csc x - \cot x| + C;\end{align*}$  
⑦ $\begin{align*}\int \sec^2 x\mathrm{d}x = \tan x + C;\end{align*}$  
⑧ $\begin{align*}\int \csc^2 x\mathrm{d}x = - \cot x + C;\end{align*}$  
⑨ $\begin{align*}\int \sec x \tan x\mathrm{d}x = \sec x + C;\end{align*}$  
⑩ $\begin{align*}\int \csc x \cot x\mathrm{d}x = - \csc x + C;\end{align*}$

::: details 推导
$\begin{align*}
\int \tan x\mathrm{d}x &= \int \frac{\sin x}{\cos x}\mathrm{d}x = \int - \frac{\mathrm{d}(\cos x)}{\cos x} = \int \mathrm{d}(- \ln |\cos x|) \\
&= \int \mathrm{d}(\ln |\sec x|) = \ln |\sec x| + C.
\end{align*}$

$\begin{array}{l}
\begin{aligned}\int \sec x\mathrm{d}x = \int \frac{1}{\cos x}\mathrm{d}x = \int \frac{\cos x}{\cos^2 x}\mathrm{d}x = \int \frac{\mathrm{d} \sin x}{\cos^2 x} = \int \frac{\mathrm{d} \sin x}{1 - \sin^2 x}\end{aligned} \\
\begin{aligned}\xlongequal{\text { 令 } t = \sin x} \int \frac{1}{1 - t^2} \mathrm{d}t &= \frac{1}{2}\int \Big(\frac{1}{1 + t} + \frac{1}{1 - t}\Big) \mathrm{d}t \\
&= \frac{1}{2}\Bigg(\int \frac{1}{1 + t} \mathrm{d}(1+t) - \int \frac{1}{1 - t} \mathrm{d}(1-t)\Bigg)\end{aligned} \\
\begin{aligned} \int \frac{\mathrm{d} \sin x}{1 - \sin^2 x} &= \frac{1}{2}(\ln |1 + t| - \ln |1 - t|) + C = \frac{1}{2}\ln \Big|\frac{1+t}{1-t}\Big| + C \\
&= \frac{1}{2}\ln \Big|\frac{1+\sin x}{1-\sin x}\Big| + C = \frac{1}{2}\ln \Bigg|\frac{(1+\sin x)^2}{1-\sin^2 x}\Bigg| + C \\
&= \ln \Big|\frac{1+\sin x}{\cos x}\Big| + C \\
&= \ln |\sec x + \tan x| + C.
\end{aligned} \\
\end{array}$
:::

5. 有理分式  
① $\begin{align*}\int \frac{\mathrm{d}x}{\sqrt{1-x^2}}=\arcsin x + C;\end{align*}$  
② $\begin{align*}\int \frac{\mathrm{d}x}{\sqrt{a^2-x^2}}=\int \frac{\mathrm{d}(\frac{x}{a})}{\sqrt{1-(\frac{x}{a})^2}} = \arcsin \frac{x}{a} + C;\end{align*}$  
③ $\begin{align*}\int \frac{\mathrm{d}x}{1+x^2} = \arctan x + C;\end{align*}$  
④ $\begin{align*}\int \frac{\mathrm{d}x}{a^2+x^2} = \frac{1}{a}\int \frac{\mathrm{d}(\frac{x}{a})}{1+(\frac{x}{a})^2} = \frac{1}{a}\arctan \frac{x}{a} + C;\end{align*}$  
⑤ $\begin{align*}\int \frac{\mathrm{d}x}{x^2-a^2} =\frac{1}{2a}\Bigg[\int \frac{\mathrm{d}(x-a)}{x-a} - \int \frac{\mathrm{d}(x+a)}{x+a}\Bigg] = \frac{1}{2a} \ln \Big|\frac{x-a}{x+a}\Big| + C;\end{align*}$  
⑥ ⭐$\begin{align*}\int \frac{\mathrm{d}x}{\sqrt{x^2-a^2}} = \ln \big|x+\sqrt{x^2-a^2}\big| + C;\end{align*}$  
⑦ ⭐$\begin{align*}\int \frac{\mathrm{d}x}{\sqrt{x^2+a^2}} = \ln \big|x+\sqrt{x^2+a^2}\big| + C;\end{align*}$  
⑧ ⭐$\begin{align*}\int \sqrt{a^2-x^2}\mathrm{d}x = \frac{a^2}{2}\arcsin {\frac{x}{a}} + \frac{x}{2} \sqrt{a^2-x^2} + C;\end{align*}$  
⑨ $\begin{align*}\int \sqrt{x^2-a^2}\mathrm{d}x = \frac{1}{2}x\sqrt{x^2-a^2} - \frac{a^2}{2} \ln\big|x+\sqrt{x^2-a^2}\big| + C;\end{align*}$  
⑩ $\begin{align*}\int \sqrt{x^2+a^2}\mathrm{d}x = \frac{1}{2}x\sqrt{x^2+a^2} + \frac{a^2}{2} \ln\big|x+\sqrt{x^2+a^2}\big| + C.\end{align*}$  


::: details 推导
$$\begin{array}{l} 
  ⑥~\int \frac{\mathrm{d}x}{\sqrt{x^2-a^2}}  \\
  令\tan \vartheta = \frac{\sqrt{x^2-a^2}}{a}, \cos \vartheta = \frac{a}{x}.  \\
  \Rightarrow \sqrt{x^2-a^2} = a \tan \vartheta, x = a \sec \vartheta.  \\
  \begin{split}
  原式 &= \int \frac{1}{a \tan \vartheta} \mathrm{d} (a \sec \vartheta) = \int \cot \vartheta \mathrm{d} \sec \vartheta = \int \cot \vartheta \tan \vartheta \sec \vartheta \mathrm{d} \vartheta = \int \sec \vartheta \mathrm{d} \vartheta  \\
  &= \ln |\sec \vartheta + \tan \vartheta| + C = \ln |\frac{x}{a} + \frac{\sqrt{x^2-a^2}}{a}| + C = \ln |x + \sqrt{x^2-a^2}| + C.
\end{split}
\end{array}$$

$$\begin{array}{l} 
  ⑦~\int \frac{\mathrm{d}x}{\sqrt{x^2+a^2}}  \\
  令\cos \vartheta = \frac{a}{\sqrt{x^2+a^2}}, \tan \vartheta = \frac{x}{a}.  \\
  \Rightarrow \sqrt{x^2+a^2} = a \sec \vartheta, x = a \tan \vartheta.  \\
  \begin{split}
  原式 &= \int \frac{1}{a \sec \vartheta} \mathrm{d}(a \tan \vartheta) = \int \cos \vartheta \mathrm{d} \tan \vartheta = \int \cos \vartheta {\sec}^2 \vartheta \mathrm{d} \vartheta = \int \sec \vartheta \mathrm{d} \vartheta  \\
  &= \ln |\sec \vartheta + \tan \vartheta| + C = \ln |\frac{\sqrt{x^2+a^2}}{a} + \frac{x}{a}| + C = \ln |x + \sqrt{x^2+a^2}| + C.
\end{split}
\end{array}$$

图二&emsp;三角函数辅助图2{.figure-caption}

$$\begin{array}{l} 
  ⑧~\int \sqrt{a^2 - x^2} \mathrm{d}x  \\
  令\cos \vartheta = \frac{\sqrt{a^2-x^2}}{a}, \sin \vartheta = \frac{x}{a}.  \\
  \Rightarrow \sqrt{a^2-x^2} = a \cos \vartheta, x = a \sin \vartheta.  \\
  \begin{split}
  原式 &= a^2\int \cos \vartheta \mathrm{d}(\sin \vartheta) = a^2\int {\cos}^2 \vartheta \mathrm{d} \vartheta = a^2\int \frac{\cos 2\vartheta + 1}{2} \mathrm{d} \vartheta = \frac{a^2}{2} (\int \cos 2\vartheta \mathrm{d} \vartheta + \int \mathrm{d} \vartheta)  \\
  &= \frac{a^2}{4} \sin 2\vartheta + \frac{a^2}{2} \vartheta + C = \frac{a^2}{2} \sin\vartheta \cos\vartheta + \frac{a^2}{2} \arcsin\frac{x}{a} + C  \\
  &= \frac{a^2}{2} \arcsin\frac{x}{a} + \frac{x}{2} \sqrt{a^2-x^2} + C.
\end{split}
\end{array}$$
![三角函数辅助图3](/img/math/calculus/3.png){.center .psmall}
图三&emsp;三角函数辅助图3{.figure-caption}

$$\begin{array}{l} 
  ⑨~\int \sqrt{x^2-a^2}\mathrm{d}x  \\
  由⑥~得:\int \sqrt{x^2-a^2}\mathrm{d}x = a^2 \int \tan\vartheta \mathrm{d}(\sec\vartheta) =a^2 \int {\tan}^2\vartheta \sec\vartheta \mathrm{d}\vartheta  \\
  令~t=\int {\tan}^2\vartheta \sec\vartheta \mathrm{d}\vartheta  \\
  \begin{split}
  t &= \tan\vartheta \sec\vartheta - \int \sec\vartheta \mathrm{d}(\tan\vartheta)  \\
    &= \tan\vartheta \sec\vartheta - \int \sec\vartheta \cdot {\sec}^2\vartheta \mathrm{d}\vartheta  \\
    &= \tan\vartheta \sec\vartheta - \int \sec\vartheta (1 + {\tan}^2\vartheta) \mathrm{d}\vartheta  \\
    &= \tan\vartheta \sec\vartheta - \int \sec\vartheta - t.  \\
  \Rightarrow t &= \frac{1}{2} \tan\vartheta\sec\vartheta - \frac{1}{2} \ln|\sec\vartheta+\tan\vartheta| + C  \\
                &= \frac{1}{2a^2}x\sqrt{x^2-a^2} - \frac{1}{2} \ln|x+\sqrt{x^2-a^2}| + C.
\end{split}  \\
  \therefore \int \sqrt{x^2-a^2}\mathrm{d}x = a^2 t = \frac{1}{2}x\sqrt{x^2-a^2} - \frac{a^2}{2} \ln|x+\sqrt{x^2-a^2}| + C.
\end{array}$$

$$\begin{array}{l} 
  ⑩~\int \sqrt{x^2+a^2}\mathrm{d}x  \\
  由⑦~得:\int \sqrt{x^2+a^2}\mathrm{d}x = a^2 \int \sec\vartheta \mathrm{d}(\tan\vartheta) =a^2 \int {\sec}^3\vartheta \mathrm{d}\vartheta  \\
  令~t=\int {\sec}^3\vartheta \mathrm{d}\vartheta  \\
  \begin{split}
  t &= \sec\vartheta \tan\vartheta - \int \tan\vartheta \mathrm{d}(\sec\vartheta)  \\
    &= \sec\vartheta \tan\vartheta - \int {\tan}^2\vartheta \cdot \sec\vartheta \mathrm{d}\vartheta  \\
    &= \sec\vartheta \tan\vartheta - \int ({\sec}^2\vartheta - 1)\sec\vartheta \mathrm{d}\vartheta  \\
    &= \sec\vartheta \tan\vartheta - t + \int \sec\vartheta \mathrm{d}\vartheta.  \\
  \Rightarrow t &= \frac{1}{2} \sec\vartheta \tan\vartheta + \frac{1}{2} \ln|\sec\vartheta+\tan\vartheta| + C  \\
                &= \frac{1}{2a^2}x\sqrt{x^2+a^2} + \frac{1}{2} \ln|x+\sqrt{x^2+a^2}| + C.
\end{split}  \\
  \therefore \int \sqrt{x^2+a^2}\mathrm{d}x = a^2 t = \frac{1}{2}x\sqrt{x^2+a^2} + \frac{a^2}{2} \ln|x+\sqrt{x^2+a^2}| + C.
\end{array}$$
:::

### 1.换元积分法  
<Badge type="note">Case1 第一类换元积分法</Badge>

$例1. \int \frac{x}{(2x+1)^2} \mathrm{d}x$  
$例2. \int \frac{\mathrm{d}x}{x^2+2x+5}$  
$例3. \int \frac{\mathrm{d}x}{\sqrt{2x-x^2}}$  
$例4. \int \frac{\mathrm{d}x}{\sqrt{x}(4+x)}$  
$例5. \int \frac{\mathrm{d}x}{\sqrt{x^2+x}}$  
$例6. \int \frac{e^x}{4+e^{2x}}\mathrm{d}x$  
$例7. \int \frac{\mathrm{d}x}{x{\ln}^2 x}$

形如 $\int f[\varphi(x)] \varphi'(x) \mathrm{d}x = \int f[\varphi(x)] \mathrm{d}(\varphi(x)) \xlongequal{\text { 令 } t=\varphi(x)} \int f(t) \mathrm{d}t=F(t)+C=F[\varphi(x)]+C.$  
$$
\begin{split}
  如:\int \frac{{\sin}^2 {\sqrt{x}}}{\sqrt{x}}\mathrm{d}x &= 2\int {\sin}^2 \sqrt{x} \mathrm{d}(\sqrt{x}) \xlongequal{\text { 令 } t=\sqrt{x}} 2\int {\sin}^2 t \mathrm{d}t  \\
  &= \int (1 - \cos 2t) \mathrm{d}t = t - \int \cos 2t \mathrm{d}t  \\
  &= t - \frac{1}{2} \sin 2t + C = \sqrt{x} - \frac{1}{2} \sin 2\sqrt{x} + C. \\
\end{split}
$$

### 2.分部积分法  
已知 $(uv)' = u'v + uv'$  
$d(uv) = d(u)v + ud(v)$  
两边同时积分:$uv = \int v \mathrm{d}u + \int u \mathrm{d}v$  
$\Rightarrow \int u \mathrm{d}v = uv - \int v \mathrm{d}u$
